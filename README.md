# Qwen Create 插件交互 Demo

浏览器本地交互原型，构建方式为原生 HTML/CSS/JS，无框架依赖。

## 演示内容

- A：悬停视频 → 点击带千问 Logo 的 Save 胶囊 → 搜索或创建文件夹 → 确认收藏；已收藏时显示 Saved。
- B：拖拽网页视频 → 千问侧边栏入口图标 → 选择文件夹 → 确认收藏。收藏成功时图标转一圈，并显示成功提示。
- 两种方式共用浏览器 localStorage 收藏库，重复收藏到相同文件夹不会创建重复记录。
- 侧边栏展开/收起、历史会话、新建会话、素材上传与网页拖拽；上传菜单只含 File、Assets、Photo。紧凑的 Auto / Image / Video 菜单支持分别选择图片和视频模型。
- 竖向参考图尺寸保持原版构图；普通横向窗口切换为可浏览的网页与侧边栏分屏，窄窗口使用侧边栏覆盖层。
- 输入框随参考素材增加高度；底部小胶囊支持横滑、鼠标拖动与滚轮。
- Optimize Prompt 用英文补充可填写占位符，不猜测用户需求；有占位符时提示填写后发送。
- 六个工具胶囊：AI Analysis、Transcript、Remake、Hooks、Script、Localization。每次产出先给出简短概括，再提供可编辑、可下载的 Markdown 文件；建议回复纵向排列，点击后作为下一轮消息发送。
- AI Analysis / Remake：分析报告 → 用户确认 → 复刻方案或脚本；Transcript：对白台词 → 用户确认 → 改写或二创方案；Hooks：三个开头方案；Script：短剧剧本；Localization：视频分析 → 印度本土化与 Video Redo 方案 → 用户确认 → 本土化脚本。
- 默认上传参考并发送需求时，先分析素材并产出创作脚本，再引导去主端生成图片、关键帧或视频。
- Thinking 使用静态文字。Agent 思考期间千问入口图标旋转，生成期间不旋转；收起侧边栏后仍保持任务状态。拖拽收藏成功时图标单次旋转。
- “去 Qwen Create 创作”和 Open in app 打开指定的主端会话链接，“查看收藏”打开指定的主端 Assets 链接；本 Demo 不同步素材、会话或收藏到主端，不进行实际计费。

## 范围

本项目不是安装到浏览器的扩展。示例视频用 AI 生成的静态封面表示，不抓取真实平台视频，不进行真实转写、生成或计费。图片和视频文件通过浏览器文件选择器读取，不上传到服务器。收藏保存在当前浏览器；更换浏览器或清除站点数据后不会保留。

## 本地预览

在本目录运行 `python3 start.py --open`（Windows 可用 `py -3 start.py --open`）。默认访问 http://127.0.0.1:8767，端口占用时以启动日志为准。详见 [DEPLOY.md](DEPLOY.md)。

## GitHub Pages 发布

仓库内置 `.github/workflows/pages.yml`，无需构建或安装依赖，直接发布 `dist/`，不会改动 Demo 的界面和交互。

首次发布需在仓库 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions，再向 `main` 推送文件或手动运行工作流。工作流成功后，以部署记录中的实际网址为准。不要将本地截图、`.openai/` 托管配置或浏览器收藏数据一并上传。
